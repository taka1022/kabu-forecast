# KABUFORECAST — 株価予測ダッシュボード

日本株10銘柄（日立・ソニー・リクルート・日本製鉄・三菱UFJ・ソフトバンクG・キオクシア・アドバンテスト・三菱重工・川崎重工）の株価予測・分析ダッシュボード。

## 機能
- リアルタイム株価取得（yahoo-finance2 / chart API）
- 株価チャート（1M/3M/6M/1Y）— 指標は常に1年分のデータで計算し、表示期間のみスライス
- テクニカル: MA5/25/75（パーフェクトオーダー判定）、ボリンジャーバンド、RSI、MACD
- 目標株価レンジ（ボラティリティベース、トレンドは±40%にクランプ）
- マクロ環境: 6因子（ドル円・米10年金利・日経・S&P500・原油・金）× 銘柄別感応度。直近5営業日の変化率を典型変動幅で正規化してスコアリング
- AI分析（Claude Sonnet 5）:
  - 自動分析 — アプリが保持する株価・テクニカル・マクロ・業績データをワンクリックで総合分析
  - コンセンサス入力分析 / アナリストレポート分析
- 統合予測スコア（テクニカル35% + マクロ35% + AI30%）
- 5分間隔の自動更新

## 技術スタック
- Next.js 14 (App Router) + TypeScript
- Tailwind CSS
- Recharts
- yahoo-finance2 v3

## デプロイ

```bash
# 依存関係インストール
npm install

# 開発サーバー
npm run dev

# Vercelへデプロイ
npx vercel --prod
```

## 環境変数
- `ANTHROPIC_API_KEY` — AI分析（Claude API）に必要
